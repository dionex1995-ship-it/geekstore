# GEEKSTORE — бесплатный интернет-магазин электроники

Современный интернет-магазин техники в стиле BigGeek, работающий полностью бесплатно на GitHub Pages.

## 🚀 Быстрый старт

1. Загрузите все файлы в репозиторий на GitHub
2. В настройках репозитория → **Pages** → выберите ветку `main` и папку `/ (root)`
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`

## 🎯 Функционал

- **Каталог товаров** с фильтрами по категории, бренду, цене и наличию
- **Поиск** товаров с выпадающими результатами
- **Страница товара** с галереей, характеристиками и похожими товарами
- **Корзина** с localStorage (работает без сервера)
- **Оформление заказа** (демо-форма)
- **Авторизация** (демо-аккаунт: demo@geekstore.ru / demo123)
- **Админ-панель** для управления товарами (пароль: admin123)
- **Адаптивный дизайн** для телефонов, планшетов и ПК

## 🆓 Бесплатный хостинг

- **GitHub Pages** — бесплатно, навсегда, с HTTPS
- **Домен** — `<username>.github.io/<repo>/` (бесплатно)
- **Свой домен** — можно подключить бесплатно через настройки Pages

## 🛠 Технологии

- HTML5 + CSS3 + Vanilla JavaScript (без фреймворков)
- LocalStorage для корзины и пользователей
- JSON для каталога товаров
- Google Fonts (Inter, JetBrains Mono)
- Unsplash для изображений товаров

## 📱 Адаптивность

Сайт корректно отображается на:
- 📱 Смартфонах (от 320px)
- 📱 Планшетах (от 768px)
- 💻 Ноутбуках и ПК (от 1024px)
